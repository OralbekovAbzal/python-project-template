# Python project template

Шаблон для новых Python-проектов: виртуальное окружение, зависимости
в `requirements.txt` и секреты в `.env`, которые не попадают в Git.

## Структура

```
template/
├── main.py           # точка входа
├── models.py         # классы данных
├── services.py       # логика
├── requirements.txt  # список библиотек
├── .env.example      # пример переменных окружения (без настоящих значений)
├── .env              # настоящие значения (не в Git)
└── .gitignore
```

## Требования

- Python 3.10 или новее
- Зависимости: `python-dotenv`

## Запуск

1. Клонировать репозиторий и перейти в папку:

   ```bash
   git clone <ссылка на репозиторий>
   cd template
   ```

2. Создать и включить виртуальное окружение:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate        # macOS / Linux
   # .venv\Scripts\activate         # Windows
   ```

3. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создать `.env` из примера и заполнить значения:

   ```bash
   cp .env.example .env
   ```

5. Запустить:

   ```bash
   python main.py
   ```

## Переменные окружения

| Переменная | Описание |
|---|---|
| `message` | Тестовое сообщение, которое выводит `main.py` |

Переменные читаются через `os.getenv()` после `load_dotenv()`.
Файл `.env` добавлен в `.gitignore` — настоящие ключи не попадают в репозиторий.

## Как использовать как шаблон

Скопировать папку под новый проект, удалить `.venv`, пройти шаги из
раздела «Запуск» и добавить свои переменные в `.env.example`.
